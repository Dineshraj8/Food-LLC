# Food, LLC — Premium Responsive Website

A polished restaurant website built with plain HTML, CSS and vanilla JavaScript.

## What's included
- `index.html` — page structure and content
- `style.css` — responsive design, layout, animations and mobile styles
- `script.js` — mobile navigation, menu category filters and demo contact-form feedback
- `assets/` — reserved for your own local images

## Run locally
1. Extract the ZIP file.
2. Open the `food-llc-premium` folder.
3. Double-click `index.html`, or use VS Code Live Server for local development.

No build tools, package installation or framework required.

## Customise
- Replace the sample restaurant name, address, phone number and email in `index.html`.
- Update sample dish names and prices in the menu cards.
- Replace the remote Unsplash image URLs with your own image files if preferred.
- The contact form is front-end only. Connect Formspree, Netlify Forms or your own backend to receive real messages.

## Images and fonts
The demo uses remote images from Unsplash and Google Fonts. An internet connection is required for those assets to load. You can download and host your own licensed images locally for production use.

## Responsive behaviour
Designed for desktop, tablet and mobile, with additional small-screen adjustments and reduced-motion support.
